# 🎓 Student Performance Analysis

## 📌 Project Overview

This project analyzes student performance using Python. The goal is to understand how students perform across different subjects and identify areas where improvement is needed.

---

## 🧠 Objectives

* Calculate average marks for each subject
* Identify the highest scoring subject
* Find students who need improvement
* Visualize student performance using graphs

---

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib

---

## 📂 Dataset

The dataset contains:

* Student Names
* Marks in:

  * Math
  * Science
  * English

---

## ⚙️ Steps Performed

### 1. Data Loading

* Created or loaded dataset using Pandas DataFrame

### 2. Data Cleaning

* Checked for missing values
* Filled missing values using mean

### 3. Data Analysis

* Calculated average marks per subject
* Found highest scoring subject
* Computed individual student averages
* Identified students with average < 70

### 4. Data Visualization

* Bar chart for subject-wise average marks
* Bar chart for student performance

---

## 📊 Key Insights

* Identified the subject with highest average performance
* Detected students who need improvement
* Observed performance trends across subjects

---

## 📸 Output Examples

* Subject-wise average marks chart
* Student performance comparison graph
